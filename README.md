# نظام ترقية المراتب والضباط

## الوصف

تطبيق ويب عربي لإدارة الضباط، متابعـة مؤشرات الأداء، وطلب/مراجعة ترقيات المراتب داخل المؤسسة أو المؤسسة الأمنية.

## المميزات

- لوحة معلومات لحالة الموظفين والطلبات
- إضافة وتحديث وحذف بيانات الضباط
- متابعة طلبات الترقية
- تقييم الأداء حسب نقاط مخصصة
- واجهة عربية سهلة الاستخدام
- قاعدة بيانات SQLite داخلية

## التشغيل

1. تثبيت الحزم:

```bash
npm install
```

2. تشغيل التطبيق:

```bash
npm start
```

3. افتح الموقع في المتصفح:

```text
http://localhost:3000
```
